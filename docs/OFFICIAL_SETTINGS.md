| 項目 | 現在値 | このアプリで作るか |
|---|---|---|
| アラームの同期 | オフ | 作らない。ペア設定した端末との同期はGoogleアカウント連携が必要 |

| 消音までの時間 | なし | **作る**。放置したときに鳴り止むまでの時間 |
| スヌーズの長さ | 5分 | **作る**。すでにアラームごとに持っているが、全体の既定値として必要 |
| アラームの音量 | スライダー | **作る**。端末のアラーム音量を直接操作する |
| 徐々に音量を上げる | 10秒（デバイスのサウンドのみ） | **作る**。すでに実装済み（5秒固定）。設定で変えられるようにする |
| アラーム時の音量ボタン | 音量の調整 | **作る**。鳴動中に音量ボタンを押したときの動作（音量調整／スヌーズ／解除） |

# 追記: アラームの音量スライダーの仕様（2026年9月6日に確定）

端末のアラーム音量を画面から動かす場合、Androidの仕組みの上で決まる扱いが多い。
このアプリはそれに合わせている。

| 項目 | このアプリの扱い |
|---|---|
| 範囲 | `getStreamMinVolume(STREAM_ALARM)` 〜 `getStreamMaxVolume(STREAM_ALARM)` |
| 初期値 | `getStreamVolume`を上の範囲へ収めた値 |
| 端末側の変更への追従 | `Settings.System.CONTENT_URI` を `notifyForDescendants=true` で監視。ビューがwindowに付いたとき登録し、外れたとき解除 |
| 自分の書き込み | `setStreamVolume`の直前に目印を立て、監視側が通知を1回だけ読み飛ばす |
| 指で操作中 | ドラッグ中と押下中は端末側の値で上書きしない |
| 書き込み | `setStreamVolume(STREAM_ALARM, 値, 0)`。フラグ0なのでシステムの音量UIは出さない。利用者が動かしたときだけ書く |
| サイレントモード | `INTERRUPTION_FILTER_NONE`、または`PRIORITY`でアラームが優先対象に入っていないときは、スライダーを無効にする |
| アイコン | 音量0のときだけ消音の絵柄へ切り替える |
| 試聴音 | 指を離したとき、値が0でなければ既定のアラーム音を鳴らす。鳴らした後**2秒**は次を鳴らさない |

下限は端末が返す値であり、0とは限らない。実機（Pixel 10 Pro）では、通常のアプリからは3が返る
（特別な権限を持つアプリには1が返る）。0まで下げられる前提で作ると、画面の表示と実際の音量がずれる。

確かめ方:

```sh
adb shell dumpsys audio | sed -n '/- STREAM_ALARM:/,/Volume Group/p'
# Min: 1 w/o perm:3   ← 通常のアプリからは3
```

# 追記: 音量スライダーの挙動（2026年9月3日に確認）

純正では、**アラームの音量スライダーを動かすと、その音量で試聴音が鳴る。**
数字だけでは大きさが分からないため、実際に聞いて決められるようにしている。

## 実装の要点

- スライダーを動かしている間、`USAGE_ALARM` で短い音を鳴らす
- 端末のアラーム音量（`STREAM_ALARM`）そのものを変える。アプリ内の値ではない
- 動かすたびに鳴らし直すと騒がしいので、指を離した時点か、一定の間隔で鳴らす
- 設定画面を離れたら止める

`AudioManager.setStreamVolume()` で音量を変え、同じ `STREAM_ALARM` で鳴らす。
純正時計と同じ挙動になる。

# 追記: 「⋮」メニューの構成（2026年9月3日に録画で確認）

純正の「⋮」メニューは次の5項目で、**それぞれにアイコンが付く**。

| 盾 | プライバシー ポリシー | **作る**。`docs/PRIVACY.md` の内容を表示する |
| 虫 | フィードバックを送信 | 作らない。送信先が要る |
| ？ | ヘルプ | 作らない |

| アイコン | 項目 |
|---|---|
| 歯車 | 設定 |
| 盾 | プライバシー ポリシー |

（`extended` は数MBあるので入れない）。
