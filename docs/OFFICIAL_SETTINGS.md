# 純正時計アプリの設定項目

実機（Pixel 10 Pro / Android 17）の設定画面から読み取ったもの。

## アラーム

| 項目 | 現在値 | このアプリで作るか |
|---|---|---|
| アラームの同期 | オフ | 作らない。ペア設定した端末との同期はGoogleアカウント連携が必要 |
| ペア設定済みデバイスのアラーム | 灰色（無効） | 作らない。同上 |
| アラームを鳴らすデバイス / アダプティブ アラーム | 灰色（無効） | 作らない。同上 |
| アラーム解除の操作 | タップ | **作る**。タップ／スワイプなどを選ぶ |
| 消音までの時間 | なし | **作る**。放置したときに鳴り止むまでの時間 |
| スヌーズの長さ | 5分 | **作る**。すでにアラームごとに持っているが、全体の既定値として必要 |
| アラームの音量 | スライダー | **作る**。端末のアラーム音量を直接操作する |
| 徐々に音量を上げる | 10秒（デバイスのサウンドのみ） | **作る**。すでに実装済み（5秒固定）。設定で変えられるようにする |
| アラーム時の音量ボタン | 音量の調整 | **作る**。鳴動中に音量ボタンを押したときの動作（音量調整／スヌーズ／解除） |
| 週の始まり | 日曜日 | **作る**。曜日チップの並び順に影響する |

## 時計（純正では「世界時計」）

| 項目 | 現在値 | このアプリで作るか |
|---|---|---|
| スタイル | デジタル | **作る**。アナログ／デジタルの切り替え |
| 時刻に秒を表示 | オン | **作る**。時計タブの主機能 |
| 自宅の時計を自動表示 | オン | 作らない。世界時計をやめたため不要 |
| 自宅タイムゾーン | (GMT+9:00) 東京、大阪 | 作らない。同上 |
| 日付と時刻の変更 | — | **作る**。端末の設定画面へ飛ばすだけ |
| 温度単位の変更 | — | 作らない。天気を持たないため不要 |

## タイマー

| 項目 | 現在値 | このアプリで作るか |
|---|---|---|
| タイマーの音 | タイマー完了 | **作る**。システムの音選択を開く |
| 徐々に音量を上げる | なし | **作る**。アラームと別に持つ |
| タイマーのバイブレーション | オン | **作る** |

## スクリーンセーバー

| 項目 | 現在値 | このアプリで作るか |
|---|---|---|
| スタイル | デジタル | 作らない |
| 夜間モード | オン | 作らない |

スクリーンセーバーはAndroidの「スクリーンセーバー」機能へ登録する仕組みで、
実装量に対して使う場面が限られる。今回は対象外とする。

# 作る設定の一覧（確定）

## アラーム

- アラーム解除の操作（タップ／スワイプ）
- 消音までの時間
- スヌーズの長さ（全体の既定値）
- アラームの音量（スライダー）
- 徐々に音量を上げる（秒数）
- アラーム時の音量ボタンの動作
- 週の始まり

## 時計

- スタイル（アナログ／デジタル）
- 時刻に秒を表示
- 日付と時刻の変更（端末の設定へ飛ばす）

## タイマー

- タイマーの音
- 徐々に音量を上げる
- タイマーのバイブレーション

## 作らないもの

| 項目 | 理由 |
|---|---|
| アラームの同期 / ペア設定済みデバイス / アダプティブアラーム | Googleアカウント連携が前提で、外部アプリからは同じことができない |
| 自宅の時計を自動表示 / 自宅タイムゾーン | 世界時計をやめたため不要 |
| 温度単位の変更 | 天気を持たないため不要 |
| スクリーンセーバー（スタイル / 夜間モード） | 実装量に対して使う場面が限られる |
