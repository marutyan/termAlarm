# 純正時計アプリの実測値

Pixel 10 Pro / Android 17 / ダークテーマ / Dynamic Color 適用済み。
画面 1080x2410px。1dp = 2.75px（392dp幅）。

**色はDynamic Colorで壁紙から生成されているため、値そのものを写してはいけない。**
Material 3 のどの役割（colorScheme のどのトークン）に当たるかを読み取って使う。

## 共通

| 要素 | 実測 | 対応するトークン（推定） |
|---|---|---|
| 画面の地 | `#130D09` | `surface` |
| カードの地 | `#2A2017` | `surfaceContainer` |
| 下部ナビの地 | `#201811` | `surfaceContainerLow` |
| 選択タブの丸 | `#DBB99E` | `secondaryContainer` |
| FABの地 | `#F4EEA9` | `tertiaryContainer` |
| 主要な操作ボタン | `#F2BC8F` | `primaryContainer` |

- 下部ナビは**5タブ**（アラーム / 世界時計 / タイマー / ストップウォッチ / おやすみ時間）
- 見出しは画面左上に大きく、右端に「⋮」
- FABは右下、角丸の四角（円ではない）

## 世界時計

- 画面上部に**秒まで含む特大の時刻**（`6:31:20`）
- その下に日付「9月3日（木）」と、右端に天気と気温
- セクション見出し「地域」
- 都市はカード状。左に都市名、その下に時差と天気、**右端に特大の時刻**
- 時差の表記は「昨日（-7時間）」「-6時間」

## タイマー

| 要素 | 実測 |
|---|---|
| カードの左右の余白 | 13dp |
| カードの角丸 | 大きい（28dp前後と見える） |
| 進捗リングの直径 | **311dp** |
| リングの線の太さ | **11dp** |
| リングの中心 | 画面中央（x=534px） |

- タイマー1件が**大きなカード**に入る
- カード左上にラベル「タイマー（3分）」、右上に閉じる「×」
- カード中央に**巨大な円形の進捗リング**。その中心に残り時間
- リングの下に**横長の丸い再生ボタン**（右寄せ、幅は画面の3分の1ほど）
- 時分秒のステッパー入力は**無い**。新規追加はFABから

## ストップウォッチ

| 要素 | 実測 |
|---|---|
| 操作ボタンの幅 | 367dp（画面幅いっぱい、左右13dp） |
| 操作ボタンの高さ | **104dp**（非常に大きい） |
| ボタンの角丸 | 完全な丸（高さの半分） |
| ボタンの左右の余白 | 13dp |

- 画面上部に**特大の経過時間**（`00:15.75`、1/100秒まで）
- ラップは**横並びのカード**で、左右にスクロールの矢印ボタン（◀ ▶）
- 各カードは3行: 周回数 / そのラップの時間 / その時点の合計
- 操作は**縦に3つ並ぶ巨大なボタン**

  - ラップ（`#3A2A1A` 地より少し明るい）

# 実機を見た利用者からの指摘（2026年9月5日）

自動テストが通ることと、見た目が正しいことは別である。
実機で操作して確認せずに完了と報告していたため、次の指摘を受けた。

## 数字の大きさ（実測して直した）

純正の数字を実測したところ、Material 3 の既定では足りないことが分かった。

| 場所 | 純正の実測 | 必要な文字サイズ |
|---|---|---|
| 世界時計の時刻 | 高さ44dp | 61sp |
| タイマーの残り時間 | 高さ40dp | 56sp |
| ストップウォッチ | 高さ44dp | 61sp |

Material 3 で最も大きい `displayLarge` は57spで、数字の高さは41dpにしかならない。
`displayMedium`(45sp)では32dpと、純正の3/4以下になる。

**数字の高さは文字サイズのおよそ0.72倍**になる。この比で逆算する。

線の太さは高さの13.1%で、標準のウェイト(400)である。

## 画面の使い方

純正のタイマーはカードが**画面の縦68%**を占め、上端は画面の10%の位置から始まる。
余白を切り詰めて要素を大きく見せている。私の実装は要素が小さく、余白が多い。

## まだ直っていない指摘

- **タイマーが純正の仕様と違う**。録画で確認する必要がある
- **ストップウォッチの時計部分が小さい**
- **ラップを刻むとボタンが下がる**。最初から下がった位置に置くべき
- **アニメーションが無い**。純正には画面遷移や状態変化の動きがある
- **タイマーは鳴る順番に並べ替える**。純正は残り時間の短い順に並ぶ

## 教訓

実機で操作して自分の目で見るまで、見た目について完了と言わない。
テストは「壊れていないこと」しか保証しない。
