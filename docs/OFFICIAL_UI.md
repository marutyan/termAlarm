# 純正時計アプリの実測値

Pixel 10 Pro / Android 17 / ダークテーマ / Dynamic Color 適用済み。
画面 1080x2410px。1dp = 2.75px（392dp幅）。

**色はDynamic Colorで壁紙から生成されているため、値そのものを写してはいけない。**
Material 3 のどの役割（colorScheme のどのトークン）に当たるかを読み取って使う。

- 時差の表記は「昨日（-7時間）」「-6時間」

# 作り直しの方針（2026年9月3日に決定）

見た目を純正へ寄せる。機能の一覧だけ揃えて見た目を寄せていなかったため作り直す。

## 下部ナビは4タブのまま

純正は5タブだが「おやすみ時間」は入れない。Digital Wellbeingと連携する機能で、
外部アプリからは同じことができない。使えないタブを置いても意味がないため。

## 天気と気温は入れない

純正の世界時計には天気と気温が出るが、これは入れない。

純正の天気アプリ（`com.google.android.apps.weather`）が外部へ公開している入口は
`FileProvider` と `BugReportContentProvider` の2つだけで、**`exported=true` の要素が
1つもない**。天気データを外部へ渡す口が存在しない。純正時計が天気を出せるのは
Google製アプリ同士の連携によるもので、署名が一致しないと通らない。

外部のAPIを使えば実装できるが、通信と位置情報が必要になり、「情報を集めない・通信しない」
というこのアプリの性格とPlayの申告が変わってしまう。天気の行そのものを置かない。

なお、純正で気温をタップすると天気アプリが開くが、これはアプリを起動しているだけで
データを受け取っているわけではない。

## 色の扱い

**実測した色の値をそのまま写してはいけない。** Dynamic Colorで壁紙から生成された値で、
別の壁紙では変わる。Material 3 のどの役割（`colorScheme` のどのトークン）に当たるかを
読み取って使う。

| 実測値 | 使うトークン |
|---|---|
| `#130D09` 画面の地 | `surface` |
| `#2A2017` カードの地 | `surfaceContainer` |
| `#201811` 下部ナビの地 | `surfaceContainerLow` |
| `#DBB99E` 選択タブの丸 | `secondaryContainer` |
| `#F4EEA9` FABの地 | `tertiaryContainer` |
| `#F2BC8F` 主要な操作ボタン | `primaryContainer` |
| `#F97758` 停止ボタン | `error` 系（要確認。目立たせる意図） |
