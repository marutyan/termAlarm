# TermAlarm プライバシーポリシー

最終更新日: 2026年9月17日

## 第1条 本ポリシーについて

本プライバシーポリシー（以下「本ポリシー」といいます。）は、marutyan（以下「提供者」といいます。）が提供するAndroidアプリケーション「TermAlarm」（以下「本アプリケーション」といいます。）における利用者の情報の取り扱いについて定めるものです。本ポリシーは、本アプリケーションをご利用になるすべての利用者に適用されます。

## 第2条 取得する情報

**このアプリは、利用者に関する情報を一切収集しません。**

- 個人情報の取得: 行いません
- 利用状況の記録および分析: 行いません
- 広告の表示: 行いません
- 外部との通信: 行いません。インターネットへの接続権限（`INTERNET`）自体を保持していません

なお、Androidの標準機能による自動バックアップはOS（オペレーティングシステム）が実行するものであり、本アプリケーション自身が通信を行うものではありません。詳細については「第5条 バックアップ」をご確認ください。

## 第3条 端末内に保存する情報

本アプリケーションが正常に動作するために、次の情報を**端末内のみ**に保存します。

| 項目 | 説明 |
|---|---|
| アラームの設定 | アラームを鳴らすため（時刻の範囲、間隔、繰り返す曜日、ラベル、ミニゲームの設定など） |
| タイマーとストップウォッチの状態 | 画面を閉じても計測を続けるため（残り時間やラップ記録など） |
| アプリの設定 | 選択した動作や外観を保持するため（アラームやタイマーの音、バイブレーションの有無、徐々に音量を上げる時間、消音までの時間、二度寝チェックまでの時間、配色テーマなど） |
| 時計ウィジェットの設定 | ウィジェットの外観を保持するため（時刻の色、背景スタイル、書体など） |
| 起床の記録 | 起床の傾向を振り返るため（鳴動ごとの予定時刻や停止時刻、無効化の方法、何回目で起きたかの集計など） |

これらの情報は端末内の本アプリケーション専用の領域に保存され、他のアプリケーションから読み取ることはできません。
本アプリケーション自身が外部のサーバーへ送信することはありません（Androidの標準機能による自動バックアップについては「第5条 バックアップ」をご確認ください）。本アプリケーションを端末から削除（アンインストール）した場合は、保存された情報もすべて消去されます。

## 第4条 情報の利用目的

本アプリケーションが端末内に保存する情報は、以下の目的のためにのみ利用します。

- アラームの設定: 指定された設定に従ってアラームを鳴動させるため
- タイマーとストップウォッチの状態: アプリケーションを終了している間も計測を継続するため
- アプリの設定: 利用者が選択した動作設定や外観設定を維持するため
- 時計ウィジェットの設定: ホーム画面上のウィジェットの外観を維持するため
- 起床の記録: 利用者が起床傾向を振り返るための履歴表示および集計を行うため

本アプリケーションは、これらの情報を上記の目的以外に利用することはありません。

## 第5条 バックアップ

本アプリケーションは、端末の機種変更時や本アプリケーションの再インストール時に設定等を復元できるよう、Androidの標準機能による自動バックアップに対応しています。なお、このバックアップはAndroid（OS）が提供する仕組みによって実行されます。

バックアップされる情報は、アラームの設定、タイマーとストップウォッチの状態、アプリの設定、時計ウィジェットの設定、および起床の記録です。

データの保存先は、利用者自身のGoogle ドライブの非公開領域です。この領域のデータは利用者本人や他のアプリケーションから読み取ることはできず、Google ドライブのストレージ容量も消費しません。本アプリケーションの開発者もこのデータを閲覧することはできません。また、Android 9以降では、端末のPINコードやパスワード等を用いて暗号化されます。

端末の設定から自動バックアップ機能を無効化することで、データのバックアップを停止できます。

## 第6条 第三者への提供

本アプリケーションは、外部へ送信する情報や保持する個人情報を保有していないため、第三者へ情報を提供することはありません。
また、本アプリケーションには外部の分析サービスや広告配信のためのライブラリ等は一切含まれていません。

## 第7条 アプリケーションの権限

本アプリケーションが利用する権限およびその理由は、次のとおりです。

| 権限 | 理由 |
|---|---|
| 正確なアラーム（`USE_EXACT_ALARM` / `SCHEDULE_EXACT_ALARM`） | 指定した時刻にアラームを鳴らすため。本アプリケーションの中核機能です |
| 通知（`POST_NOTIFICATIONS`） | アラームの鳴動や、タイマーおよびストップウォッチの経過を通知するため |
| 進行中の通知（`POST_PROMOTED_NOTIFICATIONS`） | 鳴動中のアラームおよびタイマーの残り時間を、通知欄の上部に継続して表示するため |
| 全画面通知（`USE_FULL_SCREEN_INTENT`） | 画面消灯時やロック時に、アラーム画面を表示するため |
| 起動完了の受信（`RECEIVE_BOOT_COMPLETED`） | 端末の再起動後もアラーム設定を復元して鳴らすため |
| バイブレーション（`VIBRATE`） | アラーム鳴動時に端末を振動させるため |
| フォアグラウンドサービス（`FOREGROUND_SERVICE`、`FOREGROUND_SERVICE_MEDIA_PLAYBACK`、`FOREGROUND_SERVICE_SPECIAL_USE`） | アプリケーションを閉じた状態でもアラームを鳴らし続け、タイマーおよびストップウォッチの計測を継続するため |
| スリープ解除（`WAKE_LOCK`） | アラームの鳴動時刻に端末のスリープ状態を解除するため |

**位置情報、連絡先、カメラ、マイク、ストレージへのアクセス権限は要求しません。**

## 第8条 センサーの利用

本アプリケーションは、アラーム停止時または「今日はもう止める」の実行前に提示されるミニゲームのうち、「端末を振る」または「歩く」が出題された場合のみ、加速度センサーの値を読み取ります。
読み取った値は、端末を振った回数や歩数を計測するためにその場でのみ使用し、端末内に保存したり外部へ送信したりすることはありません。なお、加速度センサーの利用に特別な権限は不要です。

## 第9条 児童のプライバシー

本アプリケーションは、13歳未満の児童から意図的に個人情報を取得することはありません。
本アプリケーションは、利用者の年齢を問わず、すべての利用者から情報を一切取得しません。

## 第10条 本ポリシーの変更

本ポリシーの内容を変更した場合は、本ページを更新し、最終更新日を改定します。
収集または取得する情報が増加するような変更を行う場合は、アプリケーションの更新時等に利用者が確認できるよう通知します。
